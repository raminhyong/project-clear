## 🌟 ภาพรวมโครงการ (Project Overview)

**Project CLEAR 2.0** ได้รับการรีโนเวทและหลอมรวมสถาปัตยกรรมใหม่จากระบบเดิมที่กระจัดกระจาย ให้กลายเป็น **Modern Static Web** ภายใต้โครงสร้างโปรเจกต์เดียวและดีไซน์ซิสเต็ม (Design System) เดียวกันทั้งหมด โดยมุ่งเน้นความเป็นส่วนตัวของนักเรียน ความปลอดภัย ความรวดเร็วในการโหลด และประสบการณ์ผู้ใช้ที่สวยงาม ทันสมัยระดับพรีเมียม

## 🏛️ สถาปัตยกรรมและโครงสร้างเส้นทาง (Architecture & Routing)

> **สถาปัตยกรรม 2 ฝั่ง (Two-Sided Architecture):** แยกฝั่งครูและฝั่งนักเรียนออกจากกันอย่างเด็ดขาดตามหลัก Dembrandt (`ui-context-and-scope`) ครูรามิลคือผู้สอนและผู้ดูแลระบบคนเดียว

### 1. หน้าหลัก — Smart Gatekeeper (Student Portal)
- 🚪 **`index.html`** — กล่องค้นหาห้องเรียนด้วยรหัสประจำตัวนักเรียน 5 หลัก (Glassmorphism)
  - **ไม่มี** การ์ดรายชื่อ 8 ห้องเรียน และ **ไม่มี** ปุ่มหรือลิงก์ใดๆ ไปหน้าครูเด็ดขาด (Zero-Leak)
  - กรอกรหัสแล้วระบบตรวจจาก `assets/js/student-map.js` และวาปไปยัง `rooms/[slug]/index.html?code=xxxxx` ทันที
  - มีการ์ดแนะนำ 6 โมดูล CLEAR (CLEAR Journey, CLEAR Prep, CLEAR Point, CLEAR AR, CLEAR Space, CLEAR Voice) ด้านล่าง

### 3. ระบบกิจกรรมและสื่อการเรียนรู้ (Activities Ecosystem)
- 🎒 **`traveler/`** — **CLEAR Journey:** การเดินทางสะสมไอเทมล่องสายน้ำ 20 จุด สะสมนก ปลา ดอกไม้ และเรือพระราชพิธี
- 📝 **`exam-prep/`** — **CLEAR Prep:** คลังข้อสอบและแบบฝึกหัดเสริมก่อนสอบ ตรวจผลและเฉลยอัตโนมัติ
- 💎 **`self-point/`** — **CLEAR Point:** ระบบสะสมแต้มพอยต์และคูปองของรางวัล ผ่านรหัสคูปองและ QR Code
- 📱 **`ar/`** — **CLEAR AR:** สื่อการเรียนรู้วรรณคดีสามมิติเสมือนจริง เรือพระราชพิธี บัตรเบาะแส และจิ๊กซอว์ปริศนา
- 🌌 **`space/`** — **CLEAR Space:** คลังผลงานสร้างสรรค์ & E-Book 3D และบอร์ดความคิดเห็น/รีแอ็กชันประจำห้อง
- 🎯 **`voice/`** — **CLEAR Voice:** ระบบประเมินเสียงสะท้อนผู้เรียน แบบประเมินประสิทธิภาพการสอนแบบไม่ระบุตัวตน

## 🎨 การออกแบบและเทคโนโลยี (Design & Tech Stack)

- **Frontend:** HTML5 Semantic + Modern Vanilla CSS (No build tools required)
- **Typography:** Google Fonts `'Prompt'` (ภาษาไทย) และ `'Inter'` (ตัวเลข/โค้ด)
- **Backend API:** Cloudflare Workers `project-clear-api` (`https://project-clear-api.raminhyong.workers.dev`) + D1 Database `project-clear-db` (Clone จาก `thai-classroom-db` ประวัติครบ 100%)
